# منصة بطاقات اليوم الوطني السعودي ٩٦
### رئاسة الشؤون الدينية بالمسجد الحرام والمسجد النبوي

منصة ويب متقدمة باللغة العربية (Production-Ready) مخصصة لموظفي ومنسوبي **رئاسة الشؤون الدينية بالمسجد الحرام والمسجد النبوي** لإنشاء بطاقات تهنئة رسمية باليوم الوطني السعودي باسم الموظف وتحميلها أو مشاركتها بأعلى دقة ممكنة وبشكل مباشر من المتصفح دون الحاجة لأي خوادم خارجية أو قواعد بيانات.

---

## 🌟 المميزات الرئيسية

1. **تصاميم رسمية حصرية (3 تصاميم فقط)**:
   - التصميم التراثي (عزنا بطبعنا ونقوش السدو).
   - التصميم الأخضر (مئذنة الحرم والزخارف الذهبية).
   - التصميم الروحاني (الحرم الشريف وجموع الطائفين والمصلين).
2. **محرك تصدير فائق الدقة (1:1 Native Resolution)**:
   - رسم الاسم مباشرة على أبعاد الصورة الأصلية الفائقة (1440 × 2560 px / 1441 × 2560 px).
   - تصدير ملف PNG نقي بدون التقاط لقطة شاشة وبدون أي تشويش أو ضغط جودة.
3. **مواءمة الخط التلقائية الذكية (Auto Font Fit)**:
   - حساب مقاس الخط تلقائياً ليناسب طول الاسم سواء كان اسماً مفرداً أو مركباً طويلاً، مع منع خروج الاسم خارج الإطار المخصص له.
4. **تحكم مرن بحجم الخط**:
   - منزلق تحكم سريع (Slider) مع زري التكبير `[+]` والتصغير `[-]` والتحديث الفوري للمعاينة.
5. **مشاركة مباشرة وتحميل سهل**:
   - دعم مباشر لـ Web Share API لمشاركة البطاقة كملف صورة مباشرة عبر تطبيقات التواصل (واتساب، تيليجرام، إكس، وغيرها) على أجهزة الجوال.
   - زر تحميل مباشر مع تسمية نظيفة للملف: `بطاقة_اليوم_الوطني_اسم_الموظف.png`.
6. **وضع المعايرة المتقدم للمطورين (Calibration Mode)**:
   - وضع تفاعلي مخصص لضبط أبعاد ومكان الاسم بدقة وسهولة عبر الرابط `?debug=true`.
7. **أعلى معايير الخصوصية والأمان**:
   - تتم كافة العمليات داخل متصفح المستخدم دون إرسال أو تخزين الاسم في أي خادم.

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: React 18 + TypeScript + Vite 6
- **التصميم والألوان**: Tailwind CSS مع لوحة ألوان الهوية السعودية الرسمية والمسجد الحرام
- **الخطوط العربية**: Tajawal و IBM Plex Sans Arabic من Google Fonts
- **محرك الرسم**: HTML5 Canvas Rendering Engine
- **الأيقونات والتأثيرات**: Lucide React + Canvas Confetti
- **الاستضافة**: جاهز للنشر الفوري على منصة Render كـ Static Site

## 🚀 تشغيل المشروع محلياً

### المتطلبات:
- Node.js (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التثبيت والتشغيل:
```bash

cd "card emp"

# 2. تثبيت الحزم (Dependencies)
npm install

# 3. تشغيل خادم التطوير المحلي

```

افتح المتصفح على الرابط الموضح في الطرفية:

## ☁️ النشر على Render (Deploy to Render)

المشروع مُعد مسبقاً للنشر التلقائي عبر ملف `render.yaml`:

### الطريقة الأولى: عبر ملف `render.yaml` (Blueprints)
1. ارفع المشروع إلى مستودع GitHub أو GitLab.
2. ادخل إلى لوحة تحكم **Render** واختر **New +** ثم **Blueprint**.
3. اربط مستودع المشروع، وسيقوم Render تلقائياً بقراءة `render.yaml` وإطلاق الموقع كـ Static Site.

### الطريقة الثانية: النشر اليدوي (Static Site)
1. اختر **New +** ثم **Static Site**.
2. حدد الإعدادات التالية:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
3. اضغط على **Create Static Site**.

## 📐 مكان تعديل إحداثيات ومكان الاسم لكل تصميم

توجد إعدادات التصاميم ومواقع الاسم في الملف:
`src/config/templates.ts`

تعتمد الإحداثيات على **نظام النسب المئوية (Percentage Coordinates)** لضمان الدقة بغض النظر عن حجم المعاينة:

```typescript
export const TEMPLATES: CardTemplate[] = [
  {
    id: "national-day-01",
    title: "التصميم التراثي (عزنا بطبعنا)",
    image: "/templates/national-day-01.jpg",
    nameArea: {
      x: 50.0,          // الموضع الأفقي (50% يعني في المنتصف تماماً)
      y: 69.8,          // الموضع الرأسي (69.8% من أعلى الصورة)
      width: 48.0,      // عرض المستطيل كنسبة مئوية من عرض الصورة
      height: 6.4,      // ارتفاع المستطيل كنسبة مئوية من ارتفاع الصورة
      fontSize: 56,     // حجم الخط الأساسي بالبكسل على الصورة الكاملة
      minFontSize: 32,  // أدنى حجم خط مسموح عند تصغير النص التلقائي
      maxFontSize: 76,  // أقصى حجم خط مسموح به
      color: "#11392B", // لون النص (أخضر داكن متناسق مع البطاقة التراثية)
      fontWeight: 700,  // وزن الخط
      textAlign: "center",
      maxLines: 1
    }
  },
  // ... باقي النماذج
];
```

## 🎛️ طريقة استخدام وضع المعايرة للمطورين (Calibration Mode)

أثناء تطوير أو مراجعة التطبيق، يمكنك تفعيل **Calibration HUD** لمشاهدة حدود مستطيل الاسم ونقطة الارتكاز المركزية وتحريكها بنقرة زر:

1. أضف `?debug=true` في نهاية رابط المحرر بالمتصفح:
   `http://localhost:3000/?debug=true`
   أو لقالب محدد:
   `http://localhost:3000/?template=national-day-01&debug=true`
2. ستظهر لوحة تحكم عائمة تحتوي على:
   - أسهم توجيه: `↑` لأعلى، `↓` لأسفل، `←` لليمين، `→` لليسار.
   - أزرار تكبير وتصغير العرض (Width) والارتفاع (Height).
   - مبدل ألوان الخط السريع.
   - زر **نسخ JSON** الذي ينسخ الإعدادات الجديدة إلى الحافظة فوراً لتلصقها في `templates.ts`.
